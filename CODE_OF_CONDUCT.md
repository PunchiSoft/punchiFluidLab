# Code of conduct

This project adopts the **Contributor Covenant, version 2.1** as its code of conduct.
The canonical text, which governs participation here, is published at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/> and is available
in several languages from <https://www.contributor-covenant.org/translations/>.

We adopt it by reference rather than copying it, so that the authoritative version and
its translations stay in one place. The Contributor Covenant is licensed CC BY 4.0 by
the Contributor Covenant project; this file adds the project-specific details below
and changes none of its terms.

## Scope

It applies in every project space: the repository, issues, pull requests, discussions,
release notes, and any private communication about the project.

## Reporting

Report unacceptable behaviour to the maintainer through
**GitHub → Security → Advisories** (a private channel) or by opening a
**confidential** issue if advisories are unavailable. Reports are handled privately,
answered within seven days, and never discussed in public without the reporter's
consent.

## Enforcement

Maintainers follow the enforcement guidelines of the Contributor Covenant: correction,
warning, temporary ban, permanent ban — proportional to the behaviour, with a written
reason and a path to appeal.

## Our own additions

Three things this project cares about beyond the baseline:

- **Technical honesty.** Do not present an unverified claim as verified. Say which
  validation level a change reaches.
- **Patience with newcomers.** A question asked twice is a documentation bug; fix the
  documentation.
- **No vendor or tool tribalism.** Criticise code and decisions, never people or the
  toolkit they happen to like.
