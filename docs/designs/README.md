# Designs

Specifications written with the Elephant-Goldfish Model before a change is implemented:
the Elephant drafts with full context, fresh Goldfish reviewers check it, and the approved
document is kept beside the code it describes. Every design is indexed from
[../README.md](../README.md).

| Design | What it specifies |
|---|---|
